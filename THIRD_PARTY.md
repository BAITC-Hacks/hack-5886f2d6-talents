# Использованные сторонние материалы и инструменты

## Материалы организаторов

- Датасет: `TechTask/data(1)/data/`, три Parquet-файла и описание полей.
  Синтетические идентификаторы; данные предоставлены для использования в рамках
  хакатона. Команда не заявляет авторство датасета.
- Стартер: `TechTask/starter(1)/starter/`. Исходные файлы сохранены;
  Python-пайплайн использует функции загрузки, построения графа и базовых метрик.
- Техническое задание: DOCX в `TechTask/`.

## Компоненты

Версии прямых Python-зависимостей закреплены в `requirements.txt` и
`requirements-dev.txt`. Названия и сведения о лицензиях сверены с установленными
дистрибутивами; их зависимости и включённые компоненты имеют собственные notices.

| Компонент | Версия | Использование | Лицензия / источник |
|---|---|---|---|
| nlohmann/json | 3.12.0 | Чтение и запись JSON в C++ | MIT; [сохранённый текст](engine/third_party/nlohmann/LICENSE.MIT), [проект](https://github.com/nlohmann/json) |
| NumPy | 2.5.3 | Численные операции Python | BSD-3-Clause и лицензии включённых компонентов; [проект](https://numpy.org/) |
| pandas | 3.0.1 | Таблицы, Parquet, CSV | BSD-3-Clause; [проект](https://pandas.pydata.org/) |
| PyArrow | 25.0.1 | Чтение Parquet | Apache-2.0; [проект](https://arrow.apache.org/) |
| NetworkX | 3.7 | Направленный граф, PageRank, Louvain | BSD-3-Clause; [проект](https://networkx.org/) |
| SciPy | 1.18.1 | Численная зависимость расчёта PageRank | Текст лицензии и bundled notices в дистрибутиве; [проект](https://scipy.org/) |
| jsonschema | 4.26.0 | Проверка JSON-контракта | MIT; [проект](https://github.com/python-jsonschema/jsonschema) |
| pytest | 9.1.1 | Тесты Python и интеграции | MIT; [проект](https://github.com/pytest-dev/pytest) |

Средства сборки: CMake и компилятор с поддержкой C++17. Проверенная Windows-сборка
использует MinGW и Ninja из установленного CLion; CLion не требуется для работы
готового исполняемого файла. Python-пакеты устанавливаются отдельно через pip,
их исходники не выдаются за код команды.

Арман также проверил Release-сборку с переносимым Zig 0.13.0 / clang 18.1.6,
CMake 4.4.3 и Ninja на Windows. Эти инструменты нужны только для сборки;
подробности и границы чистой проверки — [отчёт Армана](team/arman/REPRODUCIBILITY.md).

## AI при разработке

C++-ядро, его адаптация, тесты и часть документации разрабатывались с помощью
OpenAI Codex под управлением Артура. В этой версии продукт использует явно
описанные правила и графовые алгоритмы; обученная модель или внешний LLM API
в аналитическом расчёте не используются. Запуск решения не требует Codex,
аккаунта участника или персональных API-ключей.

Python-пайплайн данных и кластеризации, интеграция с C++, доставка статических
выгрузок, их проверки и соответствующая документация также разрабатывались
с помощью OpenAI Codex под управлением Армана.

После добавления интерфейса его фактические библиотеки и заимствованные
материалы следует внести в этот список; планируемый стек не считается уже
использованным компонентом.

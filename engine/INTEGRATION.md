# Совместимость с Python-пайплайном Армана

## Дополнение: C++ 1.2.0, следующие действия

Ядро добавляет `nodes[].next_actions` всем узлам. Схема v1 принимает как новые
результаты, так и старые без поля. CLI, формулы, роли, оценки, объяснения и топ
сохраняются. Проверены 34 теста ядра, 78 Python-тестов и реальный пайплайн на
2248 клиентах за 4.235 с на ноутбуке Артура (включая запуск Python; время зависит
от машины).

Для всех 2248 узлов прежние поля результата совпали с поставкой C++ 1.1.0;
топ и метаданные совпали полностью. Новые действия прошли JSON Schema,
повторный запуск дал тот же файл. 1723 узла получили одно действие, 525 — два;
максимальная длина текста в полном датасете — 149 символов. Три действия для
совместных ограничений проверены на синтетических графах.
Все три обязательных CSV совпали побайтово с предыдущей поставкой.
Старый результат прошёл обновлённую схему; отклонены девять вариантов
некорректного next_actions (тип, пустой/пробельный текст, длина, повторы, размер).

**Граница готовности:** интеграционный тест выявил потерю нового поля в списке
разрешённых полей Python. Включена минимальная правка `validate_result`, чтобы
сохранить `next_actions`; полный прогон сверяет списки для всех gid.
Арман готовит финальный пакет, Савелий — отображение. frontend/public/data остаётся
согласованной поставкой 1.1.0 до общего пересчёта. [Инструкция передачи](../team/artur/NEXT_ACTIONS.md).

## Изменения C++ 1.1.0

1. Оба запуска поддерживаются одной программой:
   `engine input.json result.json` и
   `engine --input input.json --output result.json`.
   В обоих случаях можно добавить `--config overrides.json`.
2. Базовые метрики читаются как из плоского узла, так и из вложенного `metrics`;
   `truncated_by_depth` также читается из `flags`.
3. Противоречащие значения одного поля в двух местах приводят к ошибке.
   Идентификатор, seed, глубина и cluster_id из вложенных метрик не копируются.
4. В результате добавлен алиас `engine: "money-graph-cpp/1.1.0"` для старого
   валидатора Python. `engine_version`, nodes, top_nodes и meta сохраняются.

Правила, пороги и формула приоритета не менялись. На всех 2248 клиентах результат
nodes и топ-20 совпали с первоначальным проверенным прогоном C++ 1.0.0.
Отдельные тесты подтверждают равенство ответов на эквивалентные плоский и вложенный
входы, включая параметры конфигурации, seed, границу обхода и Unicode-пути.

## Запуск на Windows из корня репозитория

```powershell
powershell -ExecutionPolicy Bypass -File engine/build.ps1
python -m pip install -r requirements.txt
python pipeline.py --core .\engine\build\engine.exe --out out
```

После сборки можно использовать `python pipeline.py`: программа автоматически
находит стандартный путь ядра и пишет результат в `out/`.

При Visual Studio указать `engine/build/Release/engine.exe`. Linux/macOS:

```sh
cmake -S engine -B engine/build -DCMAKE_BUILD_TYPE=Release
cmake --build engine/build --parallel 2
python -m pip install -r requirements.txt
python pipeline.py --core ./engine/build/engine --out out
```

Это вызов настоящего C++. Отдельная Python-demo здесь не используется.
Установка зависимостей и сборка выполняются до отсчёта времени пересчёта.

## Согласованный экспорт для интерфейса

Коммит `ad6b1d5` устранил потери полей из первой версии Python. Валидатор проверяет
cluster_id, полный набор gid и топ ядра. graph.json содержит плоские метрики,
все дополнительные поля C++, edge.id, `meta.is_demo=false`, `meta.config` и
полный `meta.engine_meta`. Сортировка равных приоритетов теперь числовая.

Проверяющий скрипт считает потерю любого из этих обязательных полей ошибкой,
сверяет хэш бинарника и эффективную конфигурацию с manifest. Проверка завершилась
с `failures=[]`, `warnings=[]`.

Арман и Савелий могут подключать UI к готовому `out/graph.json` и трём соседним CSV.
Для раздельной разработки синтетические `examples/` пересчитаны C++ 1.1.0;
`team/saveliy/graph.example.json` — копия общего примера. Флаг is_demo=true
в маленьком примере обозначает учебные данные, даже при расчёте настоящим C++.

как разбор фактического результата; в правилах ядра идентификаторы не зашиты.

# Проверка опубликованной версии в новой копии

Дата: 23 сентября 2026. Проверенный коммит: `c7f7bb4`.
Источник: GitHub-репозиторий `BAITC-Hacks/hack-5886f2d6-talents`.

## Условия

Репозиторий заново клонирован из GitHub в отдельный каталог и переключён на
указанный коммит. Создано новое venv без пакетов из рабочего окружения;
зависимости установлены из `requirements-dev.txt` (pip использовал кэш wheels).
Готовый engine.exe и CMake-кэш из рабочей копии не переносились.

Платформа проверки: Windows, Python 3.12.14, GNU g++ 13.1.0, Release,
CMake/Ninja/MinGW из установленного CLion. Это новая копия и окружение на том же
ноутбуке, не проверка на отдельной машине или на Linux/macOS.

## Выполненные команды

После клонирования, создания и активации нового окружения, из корня копии:

```powershell
python -m pip install -r requirements-dev.txt
powershell -ExecutionPolicy Bypass -File engine/build.ps1
python -m pip check
python -m pytest -q
python engine/tests/test_engine.py engine/build/engine.exe -v
python engine/tests/check_pipeline.py engine/build/engine.exe
python pipeline.py
```

На машине проверки Python вызывался через полный путь к `.venv/Scripts/python.exe`,
без зависимости от активации оболочки. Исходники и данные в копии после выполнения
остались без изменений: `git status --short` пуст.

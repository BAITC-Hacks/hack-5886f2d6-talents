Время приведено для одного локального прогона. Это проверка аналитического ядра
и тестового адаптера; полный пайплайн команды с CSV и интерфейсом ещё должен
быть проверен отдельно после интеграции.

Распределение гипотез при настройках по умолчанию:

| Роль | Узлов |
|---|---|
| consolidator | 106 |
| coordinator | 72 |
| distributor | 75 |
| transit | 60 |
| terminal | 1036 |
| peripheral | 899 |

Эти числа не являются проверенной разметкой или оценкой точности. Тестовый
адаптер получил 88 Louvain-кластеров с учётом одиночных изолированных узлов.
Кластеризация и её параметры в пайплайне Армана могут изменить признаки,
роли coordinator и приоритеты. Количество кластеров не зашито в ядро.

Также прошёл 21 тест CLI: все роли на заданных структурах, направленные циклы,
исключение seed из собственного охвата, неизвестные концы рёбер, повторы,
неверные метрики, конфигурация, пустые графы, петли, числовая сортировка gid,
границы int64 и пути с кириллицей. Проверка перестановки входных массивов
подтвердила одинаковый результат.

Повторение:

```sh
python engine/tests/test_engine.py engine/build/engine.exe -v
engine/.venv/Scripts/python.exe engine/tests/check_dataset.py engine/build/engine.exe
```

Второй тест сохраняет свежий отчёт и полные JSON в `engine/test-output/`.

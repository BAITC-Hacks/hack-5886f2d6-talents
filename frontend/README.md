# Интерфейс Савелия — Поток

React + Vite + TypeScript + Cytoscape.js. Один экран: топ-20 из пайплайна, направленные связи, точный поиск по строковому gid, фильтры, карточка и три исходных CSV.

## Быстрый запуск на готовых данных

Нужен Node.js 22.14+ (или совместимая LTS) и npm. Из корня репозитория:

```powershell
cd frontend
npm ci
npm run dev
```

Открыть http://localhost:5173. Полный проверенный набор Армана уже включён в public/data: 2248 клиентов, 3119 связей, 88 кластеров, топ-20, C++ 1.1.0, meta.is_demo=false. Python и компилятор не нужны для просмотра уже рассчитанного набора.

После установки пакетов интернет не требуется: шрифты системные, Cytoscape и иконки входят в локальную сборку. API, база данных, личный аккаунт и CDN не используются.

## Данные и воспроизводимость

| URL | Назначение |
|---|---|
| /data/graph.json | Граф, роли, топ, кластеры, объяснения и ограничения |
| /data/nodes_roles.csv | Все роли |
| /data/clusters.csv | Сводка кластеров |
| /data/top_nodes.csv | Приоритеты |
| /data/validation.json | Отчёт проверки исходных данных |
| /data/run_manifest.json | Версия ядра, конфигурация и хэши комплекта |

input.json и result.json рядом сохраняют происхождение значений. Интерфейс читает
graph.json, три CSV и run_manifest.json. До показа проверяет SHA-256 четырёх
артефактов, счётчики и флаг demo; manifest повторно читается после загрузки.
Несогласованный или неполный комплект приводит к сообщению и повторной загрузке.
Роли, суммы, оценки и порядок top_nodes берутся из пайплайна; gid остаются строками.

Пересоздать полный комплект из корня репозитория после настройки Python и сборки C++ по корневому README:

```powershell
python prepare_ui_data.py
```

Команда Армана пишет в frontend/public/data и проверяет весь комплект. После **успешного** расчёта нажать «Обновить файлы». Автоматического перехода на пример при ошибке нет. Не запускать несколько процессов с одним каталогом результатов.

Проверить переданные данные без пересчёта:

```powershell
python verify_outputs.py
# При работающем Vite дополнительно сверить отдаваемые байты:
python verify_outputs.py --base-url http://localhost:5173/data
```

Проверка включает JSON/CSV/result, все обязательные поля, хэши и внутренние суммы кластеров. Для проверки исходных файлов добавить `--data "TechTask/data(1)/data"`; `--core engine/build/engine.exe` допустим только для того же бинарника, которым рассчитан manifest. Пересобранный бинарник может иметь другой SHA-256.

Для самостоятельной разработки маленький согласованный пример остаётся в examples/ и team/saveliy/graph.example.json. Тесты интерфейса используют его; рабочая поставка использует полный набор.

## Экран

- Топ сохраняет ранги и неокруглённый порядок Python/C++. «Все клиенты» открывает полный список, по 50 записей.
- Точный поиск во всём наборе сбрасывает фильтры и показывает окружение, включая изолированных.
- Кластер / окружение на 1–2 шага / общий граф. Стрелки идут от отправителя к получателю; встречные переводы — отдельные кривые. Ромб — is_seed. Длинные подписи сокращены до последних 8 цифр, полный gid всегда в карточке.
- Нажатие на стрелку открывает карточку связи: полные src → dst, sum_kzt и n_tx. Ту же связь можно выбрать с клавиатуры в списке над графом. Встречные переводы показаны отдельно; кнопка переключает направление и исходные значения. Кнопки gid открывают отправителя/получателя. Фильтры, поиск и обновление сбрасывают выбор связи.
- «Что проверить дальше» показывает необязательный `next_actions: string[]` из узла, сохраняя текст и порядок. Отсутствующее поле и пустой список поддерживаются; советы во фронтенде не вычисляются. В текущем комплекте C++ 1.1.0 поля ещё нет — отображается явное сообщение об отсутствии переданных действий. После доставки поля обновить весь комплект и нажать «Обновить файлы».
- Цвет по роли или cluster_id, фильтры роли/кластера. Метрики карточки всегда из полного JSON, даже при скрытых связях.
- evidence объясняет роль, why — приоритет. Раскрываемые priority_breakdown и role_candidates.
- Исходные суммы включают петли; observed_* отдельно показаны как суммы без переводов себе. null — «Нет данных».
- Предупреждения о depth=4, неполных входящих seed, изоляции и прочих ограничениях. Неизвестные коды не скрываются.
- Экспорт скачивает исходные CSV целиком независимо от фильтров, из проверенных
  байтов открытого расчёта через Blob. Пересчёт на сервере не подменяет экспорт
  уже открытых карточек. Для нового комплекта нажать «Обновить файлы».

Проверяются уникальные строковые идентификаторы, ссылки рёбер, оценки 0–1, согласованность топа и покрытие кластеров. Несовместимый JSON даёт понятную ошибку.

## Проверки и сборка

```powershell
npm test
npm run build
npm run preview
```

Сборка: dist/. Preview: http://localhost:4173. Используйте локальный сервер, а не file://.

22 теста проверяют контракт, большие gid, исходный топ, ошибочные входы,
изоляцию, depth=4, соседей, контрольные случаи, SHA-256, смену комплекта при
загрузке и сохранение байтов CSV. Итоги браузерной проверки — [VERIFICATION.md](VERIFICATION.md).

Демо на 5 минут: [DEMO.md](DEMO.md). Аналитические объяснения: [team/DEMO_CASES.md](../team/DEMO_CASES.md). Источник формата: [CONTRACT.md](../CONTRACT.md).

Для миллиона узлов полную загрузку JSON и общий canvas следует заменить выдачей агрегатов и окружений по запросу, поиск — индексом. Целевой размер этой версии — 2248 узлов.

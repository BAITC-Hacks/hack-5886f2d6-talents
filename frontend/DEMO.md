# Пятиминутное демо

Перед началом установить зависимости, собрать C++ и проверить UI. Для живого
пересчёта использовать `npm run dev`, который читает frontend/public/data.
В Windows перед пересчётом остановить этот сервер через Ctrl+C: в проверке
Савелия работающий Vite однажды блокировал замену graph.json (WinError 5).
Терминал расчёта открыть в корне проекта, второй терминал — в frontend.

На демонстрации выполнить **живой пересчёт** `python prepare_ui_data.py`, как
требует раздел 10 ТЗ. После complete/passed запустить `npm run dev` во втором
терминале и открыть http://localhost:5173 либо нажать «Обновить файлы» в уже
открытой вкладке: ожидаются 2248 клиентов / 3119 связей / 88 кластеров и топ-20.
Пересчёт остаётся одной командой без ручного редактирования входа или результатов.
Ненулевой код завершения не выдавать за успешный запуск: остановить читатели файлов
и повторить всю команду, затем проверить комплект.

`npm run preview` читает dist/data — отдельную копию, созданную при сборке.
Если для демонстрации выбран preview, после пересчёта public/data нужно заново
выполнить `npm run build`, иначе обновление страницы покажет предыдущий комплект.

Блок устойчивости появляется только при наличии корректного `graph.meta.resilience`.
До публикации полного комплекта C++ 1.3.0 Арманом этот отрезок демо не считается
готовым: старый комплект 1.2.0 работает без блока. Для нового комплекта проверить
все восемь сочетаний и сверить показанные числа с его manifest/graph.json.
Кластер и слабая компонента — разные понятия: при структурном эксперименте
компоненты считаются без учёта направления; клиентские кластеры не пересчитываются.

Объяснения и переданные `next_actions` переформулированы для чтения аналитиком,
без изменения чисел, порядка действий, ролей и баллов. Исходный текст доступен
в «Исходные формулировки расчёта». Проценты — формат готового отношения из ядра,
не самостоятельный расчёт фронтенда. Для старых пакетов без `next_actions` блок
действий скрыт. Проверка понятности живым участником фиксируется отдельно в
[USABILITY_CHECK.md](../team/USABILITY_CHECK.md).

Запасная демонстрация встречных потоков: найти `100000000011452100`, выбрать
связь к `100000005140601100`: 16685 тенге, 2 перевода. «Показать встречные
переводы» открывает обратное направление: 15000 тенге, 3 перевода. Клик по
gid стороны открывает её карточку; «Вернуться к карточке клиента» закрывает связь.

Если жюри даёт свой gid: вставить его целиком, нажать «Найти», объяснить роль, причину проверки и ограничения, при необходимости раскрыть второй шаг окружения. После изменения данных числа сверять с текущим graph.json.

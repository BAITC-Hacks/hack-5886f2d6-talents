Независимая сверка подтвердила сохранение всех gid, оценок, рангов, направлений и текстов 88 гипотез без пересчёта во фронтенде.

- 78 Python-тестов и 28 тестов C++ CLI прошли на объединённой версии; 7 тестов UI и production build также прошли.
- `python prepare_ui_data.py --out engine/test-output/frontend-compat`: полный запуск 3.391 с, worker 1.969 с. В отдельном комплекте проверены 7 хэшей, исходные Parquet и использованный бинарник, is_demo=false.
- `python verify_outputs.py --base-url http://127.0.0.1:5173/data`: прошёл для поставки команды; все 6 URL совпали по байтам. SHA-256 manifest: `244a2add00264e10cf730c537a8d0d264a25bccf522c0565890663e72c6a3901`.
- В браузере повторно проверены лидер, транзит, depth=4, изолированный seed и скачивание всех трёх CSV. Ошибок консоли нет.
- Новые длинные гипотезы обрезались на узком экране. Исправлена высота панели: при 390×844 весь текст и нижнее примечание доступны; панель растёт вместе с содержимым. При 1440×900 и 390×844 нет горизонтального переполнения.

Проверки ниже были выполнены при первой поставке UI; контрольные карточки и экспорт повторены после объединения.

## Практические границы

Топ и суммы берутся из полного набора, даже если граф отфильтрован. Представление всего графа обзорное; для чтения направления и отдельного клиента используются кластер и окружение, масштабирование и перетаскивание. Длинные подписи на canvas сокращены; полный gid доступен в карточке и поиске.

Это проверка одного Windows-ноутбука и встроенного браузера, а не утверждение о проверке всех ОС и устройств. Финальную командную приёмку на другом компьютере провести по README. При изменении входных данных контрольные числа и gid из демо сверять заново.

## Повторная приёмка после загрузки 60e862e на ноутбук Артура

23.09.2026, Windows, Node.js 24.19.0. Аналитические файлы и их manifest не менялись.

- Исправлено смешение расчётов при экспорте: загрузчик проверяет SHA-256 graph.json
  и трёх CSV, неизменность manifest за время чтения и счётчики. Карточки и ссылки
  публикуются вместе; ссылки Blob сохраняют проверенные байты открытого расчёта.
- Основная роль исключена из списка «Другие подходящие роли».
- `npm test`: **14/14**, включая реальный полный комплект, подмену содержимого
  при сохранённом CSV-заголовке, смену manifest, неполный комплект, отмену загрузки
  и сохранение старых CSV после обновления сервера.
- `npm run build`: TypeScript и production build прошли. Предупреждение Vite
  о размере основного JS-бандла остаётся; это не ошибка сборки.
- `python verify_outputs.py --base-url http://127.0.0.1:4173/data`: passed,
  все 6 URL совпали по байтам. SHA-256 manifest прежний:
  `244a2add00264e10cf730c537a8d0d264a25bccf522c0565890663e72c6a3901`.
- В браузере проверены четыре контрольных случая из таблицы и ещё три клиента
  (`100000003016635100`, `100000003880331100`, `100000008466579100`), поиск
  изолированного seed при чужих фильтрах и неизвестный gid. В production build
  повторно проверены загрузка, лидер, вклады приоритета и альтернативная роль.
  Ошибок консоли не зарегистрировано.
- Ссылки экспорта production build содержат Blob URL и правильные имена файлов.
  Автоматизированный встроенный браузер не подтвердил событие сохранения файла
  после изменения экспорта. Поэтому **ручное скачивание всех трёх CSV в обычном
  браузере демонстрационного ноутбука остаётся финальной проверкой**; отдельно
  проверить старый открытый расчёт после пересчёта сервера и новый после обновления UI.

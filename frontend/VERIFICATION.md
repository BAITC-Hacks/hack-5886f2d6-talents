# Проверка интерфейса Савелия

23.09.2026, Windows, Node.js 22.14.0. Основа команды: коммит 4a9c671, C++ 1.1.0 и поставка frontend/public/data Армана. Все роли и оценки читаются из JSON.

## Автоматические проверки

- npm test: 7 тестов прошли; контракт, большие строковые gid, топ, некорректные входы, окружение, изолированные, null и depth=4.
- npm run build: TypeScript и производственная сборка прошли.
- python verify_outputs.py --base-url http://127.0.0.1:5173/data: passed, 7 хэшей артефактов; 6 URL совпали по байтам с файлами. 2248 узлов, 3119 рёбер, 88 кластеров, топ-20, is_demo=false.
- Дополнительно на этом ноутбуке собран исходный C++ 1.1.0 переносимым Zig 0.14.1 и выполнен pipeline.py в отдельную out/. Получены те же счётчики; общий запуск 9.250 с, worker 4.125 с. 28 тестов C++ прошли. Это отдельная проверка; поставка Армана в public/data сохранена без изменений.

## Практические границы

Топ и суммы берутся из полного набора, даже если граф отфильтрован. Представление всего графа обзорное; для чтения направления и отдельного клиента используются кластер и окружение, масштабирование и перетаскивание. Длинные подписи на canvas сокращены; полный gid доступен в карточке и поиске.

Это проверка одного Windows-ноутбука и встроенного браузера, а не утверждение о проверке всех ОС и устройств. Финальную командную приёмку на другом компьютере провести по README. При изменении входных данных контрольные числа и gid из демо сверять заново.

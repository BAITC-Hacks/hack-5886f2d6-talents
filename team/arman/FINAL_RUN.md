## Команды

Команды ниже — выполненный цикл, с локальными путями инструментов вынесенными
в переменные. Рабочая папка `$checkout` — tracked-копия указанного коммита;
venv создавался на базовом шаге. На другом устройстве достаточно стандартной
сборки из корневого README с доступным C++17-компилятором.

```powershell
$taskWork = 'C:/Users/dahan/Documents/Codex/2026-09-23/x20-hackalem-ai-5-3-parquet/work'
$checkout = "$taskWork/final-clean-9e5eff6"
$basePython = "$env:USERPROFILE/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe"
$py = "$checkout/.venv/Scripts/python.exe"
$cmake = "$taskWork/build_tools/cmake/data/bin/cmake.exe"
$ninja = "$taskWork/build_tools/bin/ninja.exe"
$cxx = "$taskWork/zig-cxx.cmd"
$env:ZIG_GLOBAL_CACHE_DIR = "$taskWork/zig-cache"
Set-Location $checkout
& $basePython -m venv .venv
& $py -m pip install -r requirements-dev.txt
& $cmake -S engine -B engine/build -G Ninja -DCMAKE_BUILD_TYPE=Release "-DCMAKE_MAKE_PROGRAM=$ninja" "-DCMAKE_CXX_COMPILER=$cxx" "-DPython3_EXECUTABLE=$py"
& $cmake --build engine/build --config Release --parallel 2
& $py prepare_ui_data.py
& $py verify_outputs.py
& $py verify_outputs.py --data 'TechTask/data(1)/data' --core engine/build/engine.exe
& $py -m pytest -q --basetemp .pytest-temp-859b33f
& $py engine/tests/test_engine.py engine/build/engine.exe -v
Set-Location frontend
npm ci
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4181 --strictPort
# Из второго терминала, cwd=$checkout:
& $py verify_outputs.py --base-url http://127.0.0.1:4181/data
```

`zig-cxx.cmd` вызывает Zig как `c++ -target x86_64-windows-gnu %*`.
При обновлении данных после production build `frontend/public/data` скопирован
в `frontend/dist/data`, затем сверены HTTP-хэши. Для обычной демонстрации сначала
выполнять `prepare_ui_data.py`, затем `npm run build`.

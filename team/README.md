# Материалы для команды

Актуальное состояние и следующие задачи для всех: [NEXT_STEPS.md](NEXT_STEPS.md).
Примеры для защиты: [DEMO_CASES.md](DEMO_CASES.md).

- [Артур — следующие действия и стыковка с Python](Artur.md).

- [Арман — данные и интеграция](arman/README.md): подключение C++, формат JSON,
  подготовка CSV и передача данных интерфейсу.
- [Савелий — интерфейс](saveliy/README.md): экран аналитика, поля данных,
  подписи ролей, ограничения и демонстрационный graph.json.

Каждый может передать свою папку своему GPT вместе с engine/CONTRACT.md и
материалами TechTask. Внутренние ссылки рассчитаны на работу с полным репозиторием.
Все обязательные поля и примеры входа/выхода ядра хранятся в engine/;
командные инструкции ссылаются на них как на основной контракт.

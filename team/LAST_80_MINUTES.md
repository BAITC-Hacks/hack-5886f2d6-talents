## Цель следующей доработки

Добавить «Что изменится в наблюдаемой сети при исключении топ-N клиентов».
Это опциональная оценка устойчивости из раздела 8 Word. Аналитик сравнит
структурную роль нескольких узлов по распаду связей, а команда покажет
количественный эксперимент. Для контроля сравним выбор по priority_score
с простым выбором по объёму переводов. Если приоритетный список окажется слабее
по этой метрике, показываем фактический результат: текущий priority_score
ранжирует проверку, а не оптимизирует разрушение сети.

## Как закрываем критерии

- **Ценность / применимость:** следующий шаг аналитика уже есть; добавляем
  проверяемый ответ о структурной зависимости графа от выбранных клиентов.
- **Качество:** исходный сценарий, единый пакет, устойчивый пересчёт и ручной экспорт.
- **Оригинальность:** осмысленное сочетание неполноты данных, направленных признаков
  и структурного эксперимента; сравнение с простым отбором по объёму.
- **Развитие:** документируем стоимость нового блока O(N log N + 9(N+M)),
  ограничения полного JSON и конкретный следующий шаг к CSR/выдаче окружений.
  Миллион узлов остаётся планом, не выполненным испытанием.
- **Демо / ответы:** готовим один реальный пример результата и объяснение,
  почему структурный распад не доказывает прекращение деятельности группы.

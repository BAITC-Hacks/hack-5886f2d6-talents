Они не заменяют обязательные выгрузки на полном датасете.
Сборка и тесты ядра не подтверждают готовность интерфейса.

### Арман — комплект данных для сдачи

Комплект текущего успешного прогона C++ 1.1.0 сохранён в `frontend/public/data/` и включён в Git: все 2248 узлов, 88 кластеров и топ-20, три CSV, graph.json, validation.json и manifest; input/result оставлены для независимой сверки. Проверены хэши и отдача всех шести URL по HTTP. Повторная доставка — `python prepare_ui_data.py`, проверка без пересчёта — `python verify_outputs.py`. 1. Передать полный graph.json Савелию и согласовать путь статических данных.
2. После подключения UI выполнить финальный расчёт одним запуском; сохранить

3. Поместить итоговые обязательные выгрузки в репозиторий в согласованную папку:
   стандартная `out/` исключена из Git. Не подменять их файлами из `examples/`.
4. Вместе с Савелием добавить проверенные команды запуска интерфейса в README.
